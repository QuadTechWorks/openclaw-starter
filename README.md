# OpenClaw — Self-Hosted AI Agent Template

A ready-to-run template for deploying a personal AI agent on your local machine using Docker.

Your agent runs as a persistent gateway accessible via a web UI, terminal TUI, and optionally Microsoft Teams. It has a customisable workspace — personality, rules, skills, and knowledge base — all editable as plain markdown files.

---

## Quickstart (3 steps)

**Prerequisites:** Docker Desktop installed and running.

```bash
# 1. Clone this repo
git clone https://github.com/YOUR_USERNAME/openclaw-template.git
cd openclaw-template

# 2. Run the setup wizard (generates .env + openclaw.json)
chmod +x setup.sh
./setup.sh

# 3. Start
docker compose up -d
```

Open **http://localhost:18789** in your browser. Done.

---

## What You Get

| Component | What it does |
|---|---|
| `openclaw-gateway` | AI agent gateway — web UI on port 18789, Teams webhook on 3978 |
| `openclaw-watcher` | Watches workspace markdown files, triggers live reloads |
| `openclaw-watcher-client` | Connects the gateway to the watcher via SSE |
| `openclaw-cli` | Optional TUI terminal client (`docker attach openclaw-cli`) |

**Stack:** `ghcr.io/openclaw/openclaw` container image (Claude Code gateway mode) + Node.js watcher + Python SSE client.

## Customising Your Agent

### 1. Identity & Personality

Edit `workspace/IDENTITY.md` to set your agent's name, role, and vibe.
Edit `workspace/SOUL.md` to add mandatory rules (tone, file delivery, formatting, etc.).

The watcher detects changes to these files and reloads the agent **live** — no restart needed.

### 2. Knowledge Base

Drop `.md` files into `workspace/knowledge/`. The agent reads them at every session start.

```
workspace/knowledge/
├── about-me.md          ← Your background and preferences
├── coding-standards.md  ← Your team's conventions
└── project-context.md   ← Current project goals
```

### 3. Skills

Skills live in `workspace/skills/`. Each skill is a folder with a `SKILL.md` that defines triggers and behaviour.

| Skill | Trigger examples |
|---|---|
| `cicd` | "set up CI/CD", "GitHub Actions", "Docker pipeline" |
| `code-quality` | "linting setup", "pre-commit hooks", "SonarQube" |
| `documentation` | "generate README", "write API docs", "CHANGELOG" |
| `engineering-standards` | "set up code quality + tests + CI/CD" |
| `observability` | "set up monitoring", "Prometheus", "Grafana" |
| `security` | "security setup", "OWASP", "secrets management" |
| `testing` | "write tests", "TDD", "test coverage" |
| `tavily-search` | "search the web", "latest news on X", "look up Y" |

To add a new skill: create `workspace/skills/my-skill/SKILL.md` and describe what it does and when to use it.

## Optional: Microsoft Teams

To connect your agent to Teams:

1. Create an Azure Bot and get the App ID, App Password, and Tenant ID.
2. Set up a free [ngrok](https://ngrok.com) account and get a static domain + authtoken.
3. Run setup.sh (or add the values to `.env` manually).
4. Start with the Teams overlay:

```bash
docker compose -f docker-compose.yml -f docker-compose.teams.yml up -d
```

5. Set the Teams bot messaging endpoint to: `https://YOUR_NGROK_URL/api/messages`

## Day-to-Day Commands

```bash
# Start
docker compose up -d

# Stop
docker compose down

# View gateway logs (shows pip install progress on first run)
docker compose logs -f openclaw-gateway

# Attach to TUI terminal client
docker attach openclaw-cli

# Restart after editing openclaw.json
docker compose restart openclaw-gateway

# Update to latest image
docker compose pull && docker compose up -d
```

---

## Adding Python Packages

Edit `requirements.txt` in the repo root and restart the gateway:

```bash
docker compose restart openclaw-gateway
```

The `entrypoint.sh` detects the change via SHA-256 hash and reinstalls only when the file changes.
